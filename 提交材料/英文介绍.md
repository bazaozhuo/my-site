## 3. Long (~270 words)

```
This is a small personal site, and it does three things.

The first is a wall of quotes: fifteen lines from fourteen voices, each with the original English, a Chinese translation and the person who said it. Every quote carries a topic tag, so the wall can be filtered down to one idea, and clicking an author opens a page with everything they said here. There is also a full-screen view that shows one line at a time, because a quote deserves a screen rather than a card in a grid.

The second is a project list. One entry is finished and online; the other three are written down with the part that would make them worth building: a browser sampler that cuts traditional Chinese instrument phrases onto a sixteen-step grid under an English rap verse, a time capsule that encrypts a letter in the browser so even the site cannot read it, and a terminal for a ship that stopped answering. I keep the technical core next to each idea, so I can tell later whether it was a real plan or a nice sentence.

The third is the useless machine: a figure in a rowboat on a night lake. Click the water and the boat rows there, oars swinging, ripples spreading, the treeline drifting a little. Arrow keys do the same without a mouse. No score, no goal and no ending, which is the point.

Everything is plain HTML, CSS and JavaScript. The navigation is generated in one file, and the quotes live in a single data file that feeds the wall, the banner and the author pages.
```

## 5. Technical summary

```
Pages        7 (home + 4 quote views + projects + machine)
Quotes       15 lines, 14 authors, one data file (js/quotes-data.js)
Nav          generated in js/nav.js — one definition, every page just has <header id="siteNav">
Author pages one HTML file, filtered by ?name= — no page per author
Effects      canvas particles for the fireworks, one SVG scene for the lake
Theme        CSS variables + html[data-theme], remembered in localStorage
A11y         axe-core 0 violations on 4 pages × both themes, 390px no horizontal scroll
Stack        plain HTML, CSS and JavaScript — no framework, no build step, no backend, no external fonts
```
